Privacy boundaries

Local means local.

No hosted memory service, no telemetry, no mystery sync.

Runs locally

The index, journal, config and logs stay on your machine.

0

No model calls

The kit reads and writes files. It does not call a model.

Private means absent

Private workspaces are removed from the cass index entirely.

Untrusted and redacted

Recall is labelled as history. Common secrets are redacted.

One honest footnote. memsearch, if you use it, summarises Claude turns with your own Claude. That's the only model in the loop, and it's optional.
